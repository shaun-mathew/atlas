# Geography Learning

The shared language for a geography-learning product that teaches geographic recognition, spatial recall, and concise facts about places.

## Geographic domain

**Geographic entity**:
A named place or geographic feature that can be learned and tested.
_Avoid_: Thing, location

**Country or territory**:
A political or geographic entity represented by the product's explicit geography policy.
_Avoid_: Nation when the entity may be a territory or disputed area

**City**:
A named urban place represented as a geographic entity with a canonical location and geographic relationships.
_Avoid_: Municipality when the learning scope is broader than a legal administrative definition

**Major city**:
A curated city included for educational significance, population, global relevance, or geographic coverage.
_Avoid_: All cities, which is not a bounded learning set

**Water feature**:
A geographic entity such as a river, lake, sea, or ocean.
_Avoid_: Body of water when referring to the broader category

**Geographic relationship**:
A meaningful connection between entities, such as a city being associated with a country or a river crossing countries.
_Avoid_: Attribute when the connection has its own geographic meaning

## Learning model

**Learning item**:
One learnable combination of a geographic entity and a skill or fact.
_Avoid_: Question, which refers to a particular assessment presentation

**Skill**:
A distinct capability about an entity, such as name-to-location, location-to-name recognition, shape recognition, or capital identification.
_Avoid_: Knowledge score, which hides the capability being measured

**Question direction**:
The direction in which a question connects an entity's name or facts to its geographic location.
_Avoid_: Question mode, which also includes adaptive and facet selection

**Name-to-location**:
A spatial-recall skill in which the learner is given an entity name and selects its location on a map or globe.
_Avoid_: Locate, which is too vague to distinguish the direction

**Location-to-name recognition**:
A recognition skill in which the learner is shown a location and selects the entity from a searchable set of candidates.
_Avoid_: Free recall, which is not part of the initial product

**Proficiency**:
The learner's demonstrated level for a particular learning item and skill.
_Avoid_: Overall score, which collapses distinct capabilities

**Adaptive mode**:
A learning mode that selects learning items from the learner's diagnostic results and scheduled reviews.
_Avoid_: Smart mode, which does not explain what adapts

**Facet mode**:
A learning mode in which the learner chooses entity scope, geographic filters, and skills or facts to practice.
_Avoid_: Category mode, which conflates entities with skills and filters

**Difficulty context**:
The amount and type of geographic context presented with a question, from rich local context to reduced context or a silhouette.
_Avoid_: Level, which can also mean progression stage

**Review**:
A scheduled return to a learning item to measure retention and update proficiency.
_Avoid_: Retry, which implies immediate repetition after failure

## Learning content

**Fact card**:
A concise explanation shown with an entity after an answer, containing selected facts that can later be tested.
_Avoid_: Blurb, which is informal and does not imply structured learning content

**Population indicator**:
An informational signal showing whether an entity's population is increasing, decreasing, or otherwise changing over a stated period.
_Avoid_: Population question, because it is not initially an assessed skill

**Fact version**:
The dated interpretation of a fact that was valid and presented at a particular point in time.
_Avoid_: Current fact, which erases the historical context of learner results

## Learner identity

**Guest profile**:
A learner profile used before account creation that can later be transferred into an account.
_Avoid_: Temporary user, which suggests progress is disposable

**Account**:
An authenticated learner identity that can retain progress across sessions and devices.
_Avoid_: Login, which describes an action rather than the identity
